\section{How FIDO2 Works}
This section offers a quick introduction into the FIDO2 ecosystem. FIDO2 can be described by combinging the W3C WebAuthn API with the CTAP protocol by FIDO~\cite{fido2-spec}, it's a public key based origin-bound authentication method.

\subsection{Core Roles}
\begin{enumerate}
  \item \textbf{Relying Party (RP):} The service that requests authentication and stores the public key.
  \item \textbf{Client:} The browser which mitigates communication between the RP and the authentication hardware.
  \item \textbf{Authenticator:} The device (Like a Yubico key or Android Strongbox) that generates and stores private keys and asserts identity \cite{fido2-spec}.
\end{enumerate}

\subsection{Cryptographic Mechanism}
FIDO2 relies on public-key cryptography, there is no exchange of shared secrets like in a password based environment.
\begin{itemize}
    \item \textbf{Registration:} The authenticator generates an asymmetric key pair inside a Secure Element. The \textbf{private key} never leaves the device, while the public key is sent to the RP.
    \item \textbf{Authentication:} The RP issues a random challenge, then using the private key the authenticator signs this challenge, this creates a \textbf{digital signature} proving possession of the credential and verifies the origin without ever revealing the private key over the network \cite{fido2-spec}.
\end{itemize}
\subsection{Safety \& Security Architecture}
There are multiple security features that make FIDO2 a strong standard \cite{fido2-spec}, like:

\begin{itemize}
    \item \textbf{User Verification:} For the authenticator to proceed with "User Presence" is not enough, meaning that by stealing the hardware attackers won't be granted access, to login "User Verification" is needed, this could be biometrics or other method, like using a PIN.
    
    \item \textbf{Origin Binding:} The authenticator checks where the request comes from, making the standard phishing proof, because this origin can not be tampered, since that would break the digital signature.
    
    \item \textbf{Attestation:} During setup, the authenticator shows a digital manufacturing certificate to the server, for legitimacy verification
\end{itemize}
