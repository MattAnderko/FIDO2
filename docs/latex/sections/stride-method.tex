\section{STRIDE Threat Modelling Framework}\label{sec:stride}
When evaluating the security of the authentication methods, we applied a framework that allow us to analyse them and compare their security, the tool of our choosing was the STRIDE threat modeling framework. It creates an abstraction of real-world attacks by grouping them into the following types:

\vspace{0.3em}
\noindent
\textbf{STRIDE categories:}
\begin{itemize}
  \item \textbf{Spoofing}: In a spoofing attack the bad actor pretends to be a valid user to gain access, this may happen via credential theft or session hijacking.
  \item \textbf{Tampering}: Tampering attacks mainly focus changing on the message content in transit, while staying undetected.
  \item \textbf{Repudiation}: Repudiation can be defined by successfully stating that an action was not performed by the user.
  \item \textbf{Information Disclosure}: Information disclosure is the category, where sensitive data gets exposed to actors with no permission to access it.
  \item \textbf{Denial of Service}: In a DoS attack one or more user loses access to the service. This may  happen by flooding the server with requests or by getting users locked out of their accounts. 
  \item \textbf{Elevation of Privilege}: Elevation of privilege happens when bad actors get admin rights. This may happen by stealing credentials or adding themselves to more privileged groups.
\end{itemize}
